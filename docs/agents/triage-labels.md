# Triage labels

As skills usam cinco papéis canônicos de triagem. Neste repositório, cada papel corresponde ao label GitHub de mesmo nome.

| Papel da skill | Label GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Um mantenedor precisa avaliar a issue. |
| `needs-info` | `needs-info` | Aguardando mais informações do autor da issue. |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para um agente. |
| `ready-for-human` | `ready-for-human` | Requer implementação humana. |
| `wontfix` | `wontfix` | Não será implementada. |

Quando uma skill mencionar um desses papéis, aplique o label GitHub correspondente.
