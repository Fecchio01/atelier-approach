# Análise comercial v1

Esta versão é executada por regras determinísticas no servidor. Os campos do cadastro são observações registradas, não fatos verificados. Evidências externas só entram quando estão marcadas como verificadas e mantêm seu identificador de origem. Ausência de dado vira desconhecido. A aderência a serviços é apenas uma correspondência textual com o escopo e os entregáveis preenchidos pela equipe. Nunca inferir orçamento, receita, desempenho, necessidade ou preço. Toda ação exige revisão humana.
