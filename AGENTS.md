## Agent skills

### Issue tracker

Use GitHub Issues em `Fecchio01/atelier-approach` por meio do `gh`. PRs não são tratados como pedidos de triagem. Consulte `docs/agents/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` e `wontfix`, conforme `docs/agents/triage-labels.md`.

### Domain docs

Repositório de contexto único: consulte `GLOSSARY.md` na raiz e as decisões relevantes em `docs/adr/`. Crie esses documentos quando termos ou decisões forem esclarecidos, não antecipadamente. Consulte `docs/agents/domain.md`.
